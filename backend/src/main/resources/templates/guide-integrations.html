1. パッケージレジストリ（自動照合対応）

製品名から自動的にパッケージの実在・バージョンを照合できるレジストリです。このデプロイ（closed-mode）では、 これらのレジストリへアイテムごとにライブ照会することはなく、事前にローカルへ同期済みのミラーデータに対して照合します。 照合そのものは通常どおり動作しており、以下は対応エコシステムの一覧です。

2. 脆弱性データソース

ソースタグ発火条件認証
NVD (NIST)nvdCPEが確定している場合不要
OSV.devosvエコシステム・パッケージ名が確定している場合不要
GitHub Security Advisoriesghsa現在無効（発火しません）。未認証60req/hourでは件数あたりの実行に非現実的なため、コード上は残るがコンポーネント未登録。相当分はOSV.devが既に取り込み済み-

本製品はNVD APIを使用していますが、NVDの認定・保証を受けたものではありません。

脆弱性情報の一部はGitHub Advisory Database（GHSA、上記のghsa・および相当分を取り込んでいるosv由来）に基づいています。 GitHub Advisory DatabaseのデータはCC BY 4.0ライセンスのもとGitHub・各アドバイザリー作成者により提供されています。

3. 自動照合できない配布チャネル

以下のような配布チャネルには専用の自動照会アダプタがありません。製品がこれらに該当する場合、 現在このデプロイでは識別・脆弱性調査ができません。

  • VS Code Marketplace（拡張機能）
  • Chrome ウェブストア（拡張機能）
  • Docker Hub（コンテナイメージ）
  • Homebrew（macOS/Linuxパッケージ）
  • Linuxディストリビューションの各パッケージマネージャ（apt/rpm等）
  • 各種App Store / モバイルアプリストア

4. ベンダー公式アドバイザリー（CSAF等）

Siemens ProductCERT・Red Hat Product Securityが公開するCSAF形式のセキュリティアドバイザリーは、既知のCVEに 対してベンダー独自の適用可否ステータス（修正済み／影響あり／影響なし／調査中）を注記として表示します（他の 情報源が該当CVEを見つけた場合のみ表示——CSAF単独でしか見つからないCVEについては、修正済み・影響ありの場合の み新規に表示します）。Ciscoについては専用アダプタが未実装です（システムレベル認証情報が必要なため）。

Red Hat Product SecurityのCSAFデータはRed Hatにより CC BY 4.0ライセンスのもと提供されています。 原文はRed Hat CSAF VEXアーカイブで参照できます。
