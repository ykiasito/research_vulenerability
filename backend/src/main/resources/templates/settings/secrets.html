NVDキーについて

この画面は管理者アカウントにのみ表示されます（閉域モード backlog item 393 — 一般ユーザーが登録したキーはどの処理からも参照されないため）。 このアプリはジョブ実行中にNVDへ問い合わせることはありません（ライブ照会は行いません）。 キーが実際に使われるのは管理者アカウントによる「CPE辞書のキーワード指定同期」と、 （有効化している場合の）「週次CPE辞書再同期」「NVD脆弱性の定期取り込み」の3つだけで、 そこでのNVDへのリクエスト間隔が緩和されます（未登録: 5リクエスト/30秒 → 登録済み: 50リクエスト/30秒）。 管理画面の「CPE辞書フル同期」「NVD CVE今すぐ同期」、および起動時のフル同期はキーを使いません （キー登録の有無に関わらず未登録時の速度のまま実行されます）。費用は一切かかりません（無料で登録できるAPIキーです）。

取得手順: NVD API Key申請ページ でメールアドレスを入力 → 届いたメールのリンクをクリックして有効化 → 表示された文字列（UUID形式）を下のフォームに貼り付け。 発行に数分〜1営業日程度かかる場合があります。
