NVDキーについて

CPE辞書のライブ照会・NVD脆弱性検索が速くなります（未登録: 約6.5秒に1回 → 登録済み: 約0.7秒に1回）。 費用は一切かかりません（無料・登録するだけのAPIキーです）。このアプリはあなたのジョブ実行時、 あなた自身が登録したキーだけを使います。

取得手順: NVD API Key申請ページ でメールアドレスを入力 → 届いたメールのリンクをクリックして有効化 → 表示された文字列（UUID形式）を下のフォームに貼り付け。 発行に数分〜1営業日程度かかる場合があります。
