パッケージレジストリミラー同期

crates.io / RubyGems / Packagist / Hex / npm / PyPI / NuGet / Go / pub.dev の9レジストリ分のミラー （registry_package_mirror）を、これまでにこのアプリが実際に解決したパッケージ名 （identified_productsに記録済みのもの）を元に同期します。Maven Centralはミラー対象外です。

観測済みパッケージ名の件数に応じて時間がかかります。ボタンを押すとサーバー側のバックグラウンドスレッドで 開始し、このページはすぐに応答を返します。進捗・完了はバックエンドのログで確認してください。

既に同期が実行中の場合は、このボタンを押しても新たな同期は開始されません（二重起動防止）。
