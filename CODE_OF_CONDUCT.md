# Code of Conduct

## Our pledge

This is a small, personal project. We want participation here — through Issues, pull requests, or discussion — to be a positive experience for everyone, regardless of background or experience level.

## Expected behavior

- Be respectful and considerate in comments, issues, and pull requests.
- Give constructive feedback, and be open to receiving it.
- Focus criticism on the code/idea, not the person.

## Unacceptable behavior

- Harassment, insulting or derogatory comments, and personal or political attacks.
- Publishing others' private information (e.g., a physical or email address) without explicit permission.
- Any other conduct that would reasonably be considered inappropriate in a professional or community setting.

## Scope

This applies to all project spaces (GitHub Issues, pull requests, and discussions on this repository) and to anyone representing the project in public spaces.

## Enforcement

This project is maintained by a single person on a best-effort basis. If you experience or witness unacceptable behavior, please report it by opening a private report via GitHub (see the repository's [Security tab](../../security) if the issue is sensitive, or contact the maintainer directly through their GitHub profile). Reports will be reviewed and addressed as promptly as possible; the maintainer may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct, and may temporarily or permanently ban anyone for behavior deemed inappropriate.

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1, simplified for the scale of this project.
