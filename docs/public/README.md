# docs/public — 設計・進捗ドキュメント(公開版)

このディレクトリは、社内の設計正本(`docs/spec/`、非公開)の中から一般公開してよい内容を整理して転記したものです。CSVアップロード型の脆弱性事前調査Webアプリ(Spring Boot + Python/FastAPI + PostgreSQL)の設計・実装状況・既知の制約をまとめています。

**非公開のまま維持しているもの**: タスクバックログ・エージェント稼働ログ(運用管理用ファイル、外部公開の対象外)。それ以外の内容についても、公開に際して以下の観点で内容を精査・調整しています: 実クレデンシャルの平文記載の伏せ字化、組織・個人を特定しうる情報の一般化、内部運用の生々しい詳細(具体的な金銭残高等)の削除。

- [architecture.md](./architecture.md) — 技術スタック、認証・セッション設計、ルーティング一覧、非同期処理の設計、外部API連携一覧。
- [pipeline.md](./pipeline.md) — 調査パイプラインの4段構成(Stage1製品識別〜Stage4 AI最終手段)の詳細設計、各Tier/Stageのコスト特性。

## 読み方の補足

各ドキュメントは作成・改訂された時点のスナップショットとして書かれており、後続の改訂で数値や結論が更新されている場合はドキュメント内に追記・訂正の形で残しています(数字を差し替えて経緯を消すのではなく、訂正の経緯自体を記録として残す方針)。最新の正式な指標定義・判定は`goals-and-constraints.md`を優先して参照してください。
